# 漁夫の利ゲーム

あなたは漁夫ではなく… なんと鷸！蚌をなるべく長く啄みながら、漁夫の網がかかるのを避けろ！

## コントロール

- **ホールド** マウスの左クリックをホールドするかスペースキーで啄む。
- **リリース** マウスを離して、逃げる。
- **R** か **もう一度盗む** リトライ！
- 右上の音量ボタンでミュートにできます。

## 技術諸々

- Vite + Three.js
- アニメーションと音はスクリプトに書きました。
